# 📊 Excel Sales Dashboard Project

## 🔎 Overview

This project presents an **interactive Sales Analysis Dashboard** built in Microsoft Excel to explore business performance using data visualization and pivot-based analytics.

The dashboard helps identify sales trends, profit distribution, customer insights, and regional performance through dynamic filters and charts.

---

## 🎯 Project Objectives

* Analyze sales and profit trends over time
* Identify top-performing categories and regions
* Visualize monthly sales patterns
* Build a clean, interactive Excel dashboard for decision-making

---

## 🧰 Tools & Techniques Used

* **Microsoft Excel**
* Pivot Tables & Pivot Charts
* Slicers for interactive filtering
* Data cleaning & formatting
* Dashboard layout design

---

## 📈 Dashboard Features

* ✔ Year-wise filtering using slicers
* ✔ Category-wise performance analysis
* ✔ Monthly sales trend visualization
* ✔ Profit distribution insights
* ✔ Regional/state sales comparison
* ✔ Interactive and user-friendly dashboard layout

## 🚀 How to Use

1. Download the Excel file from this repository
2. Open in Microsoft Excel (recommended: Excel 2016 or later)
3. Use slicers to filter by **Year** or **Category**
4. Explore charts and pivot summaries for insights
